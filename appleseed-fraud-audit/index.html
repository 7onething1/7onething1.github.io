The Appleseed Cast tab work, audited

Every claim checked against the files and the live services, 10 August 2026. Note counts read by parsing each .gp5. Stem levels measured with ffmpeg astats. Songsterr state read from its public API and song pages.

Is it fraud?
The shipped page is honest. A live rebuild is not.
The published page matches the files exactly, 0 mismatches across 40 numeric rows, and it prints silent rather than a fake number on all six empty lanes. One background job running right now is writing bass parts over near-silent stems, and the reality gate does not cover it.
Do all the songs have guitar, bass and drums?
No. 46 of 56 songs, and 6 of those carry an empty lane.
Two Conversations (2003), 10 songs, has no all-parts file at all. Five songs ship with no bass, one with no drums.
Are they synced to YouTube?
No. Zero of the 46 files are on Songsterr.
Nine tabs sit in the account, six of them drums only. The upload step is still open in STATE.md, waiting on your authorisation.

The live problem

A job started at 1:21 PM today is writing ungated files. batch_twoguitar.py, PID 44900, builds a four-track version of each song whose guitar stem splits into two parts. It has no level check of any kind. The reality gate that catches this, verify_allparts.py, globs *-ALLPARTS.gp5 at line 65, so every *-4TRACK.gp5 it writes passes unexamined.

This is the same defect the 9 August pass found and fixed for drums, where Messenger took 319 drum notes over a kit measuring below -100 dBFS. It has come back for bass, because the new script never inherited the gate.

One stale claim in the notes

STATE.md publishes a table showing Bird of Paradise bass: 1 before, 522 after, presented as the outcome of the octave-fold fix. The shipped file holds 0. The fold did restore 522 notes, and strip_silent_tracks.py emptied the track 27 minutes later because the stem measures -63.5 dBFS. The live page prints silent for that cell and is correct. The note was never updated.

What would fix it

  • Point verify_allparts.py at *-4TRACK.gp5 as well as *-ALLPARTS.gp5, so the new files are gated by the same rule.
  • Give batch_twoguitar.py the lane level check before it transcribes, the one already written in lane_levels.py.
  • Re-separate Convict and A Tree for Trials before calling their bass missing. Their low end may have gone into other at -20.7 dBFS rather than into bass.
  • Correct the Bird of Paradise row in STATE.md.
  • Build Two Conversations, or state on the page that the scope is four records.
  • Authorise the Songsterr run to get any of this synced to YouTube. Order matters: the YouTube link first, then the .gp5 import.
