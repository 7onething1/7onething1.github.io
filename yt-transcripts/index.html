Davis Mattek & Ship Chasing

A searchable index of the captions on two YouTube channels. The caption text itself is a local corpus and is not published from this page — what ships is the metadata below, and every hit points back at the second it came from on the source video.

Corpus is empty. Nothing has been fetched yet. Fill the two channel URLs into sources.json, then run the harness from this folder on a machine that can reach YouTube. 
pip3 install -U yt-dlp
python3 fetch.py                 # every source, newest 40 each
python3 fetch.py --limit 100     # go deeper
python3 fetch.py --source mattek # one channel only
python3 fetch.py https://www.youtube.com/watch?v=...   # ad-hoc

Captions land in _local/transcripts/, which is gitignored. fetch.py rewrites manifest.json — id, title, channel, date, duration, word count — and that is the file this page reads. Commit the manifest, leave the text where it is.

How it was built

fetch.py asks yt-dlp for each video's caption tracks and prefers a human-written English track over a machine one, recording which it got in the Captions column above — an auto row is a speech recogniser's guess and should be read as one. YouTube's automatic captions arrive as a rolling window in which each event repeats the tail of the one before it; the parser drops those repeats both by the aAppend flag that marks them and by a prefix check behind it, so the text is not doubled either way.
