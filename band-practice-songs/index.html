What went wrong first

The earlier pass cut the tape into 100 equal 2:15 slices on a blind clock grid. A slice boundary landed wherever the timer said, so songs were cut in half and every false start, tuning pause and bit of chatter stayed in. That answered a request for tenths and it did not answer the real ask.

How these were found

The detector treats a false start as a take the band tried again. It compares each take head-to-head against the takes that follow using chroma-sequence similarity with lag alignment, so the same pitch classes have to appear in the same order. Duration and loudness alone would mislabel almost everything, since talking is loud and a rehearsal room is never silent.

Where the honest gaps are

The speech confirmation returned nothing. All 83 takes came back UNKNOWN with zero contradictions. The room is silent between takes on this tape, so whisper had no talk to transcribe. That check gave no independent confirmation here and is not counted as a pass.

Song 14 reads 83% above the room floor and is the one file still flagged. Its gap analysis found zero stops over 1.2 seconds, so the low reading is a quiet passage rather than chatter. Kept on that evidence.

Songs 17, 18 and 19 came out of one 35.5 minute block. Two independent methods agreed on where to cut: silence gaps at 8:24 and 28:42, and a tempo analysis run on 2026-08-18 that found boundaries at 8:50 and 28:41. The cuts sit on the gap edges, so no music was clipped.

Song 20 is a single 24:42 jam and was left whole. It holds one 1.6 second gap across the entire span, so there is no evidence it contains separate songs.
