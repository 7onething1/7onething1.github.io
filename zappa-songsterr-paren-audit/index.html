Verdict

Your hunch was right about length, and backwards about the cause

Hand tabs are shorter. Median 92 bars against 181 for the AI transcriptions. The AI tabs run the full record; the hand tabs stop early or cover a section.

But the parentheses are not an AI artefact. All 17 AI tabs carry exactly zero. Every one of the 358 parenthesised drum notes sits on a hand-tabbed track.

Montana settles it inside a single tab. It holds three drum tracks: the human-tabbed 1 Ralph Humphrey with 212 parenthesised notes, a Percussion track with 105, and Songsterr's own AI drum track with 0. Same song, same page, same uploader — the human tracks carry it and the AI track does not.

What the parentheses actually are

In Songsterr's note model there is no ghost-note property in the Guitar Pro sense. Each note is fret + string plus flags, and the one that draws a parenthesised notehead is ghost: true. Confirmed by eye: Zomby Woof bar 4 carries {"fret": 38, "ghost": true} — MIDI 38 is the acoustic snare — and the rendered page shows a notehead inside brackets at exactly that bar.

So the thing you were seeing on snare hits is the ghost flag, and the answer to “parentheses instead of what?” is already written into our own drum pipeline:

The house rule, from our notes

Ghost notes get the staccato dot at velocity 31, never the parentheses. Your words, twice, recorded in stems-to-guitar-pro-drums: “parentheses used to be let ring not ghost” and “when you do the note with parentheses is hard to not hit it, just add the correct dot to it.”

In Guitar Pro terms that is the ghostNote effect flag, which our writer sets to False while adding a staccato dot instead. preflight_import.py already hard-refuses any import carrying them, with the message PARENTHESES n ghostNote flags (ghosts must be the staccato dot).

Worth saying plainly: parentheses for ghost notes are a common convention in published drum charts. This is a house standard, set because they read as let-ring and because a bracketed note is hard to play as the quiet hit it is meant to be, not a universal notation error.

Method

Song list from Songsterr's search API, filtered to both album tracklists including live and alternate versions. Source classification from /api/meta/{songId}/revisions, whose createdVia field records AI for an original AI transcription, GP for a Guitar Pro import and Editor for an in-editor edit. Notation read from the per-part JSON on Songsterr's CloudFront origin, counting the ghost flag per track and mapping each fret value through the GM percussion map to name the drum.

The measure was validated before it was trusted: a first pass counted the tie flag and would have reported Zomby Woof's parentheses at bars 16–44. Loading the page showed the bracketed notehead at bar 4 instead, which is a ghost, not a tie. The ghost key had been missed because the first schema sample came from Cheepnis, which has none.

Two caveats. Sync column reports whether Songsterr holds an original synced video, which every tab has except the 9-bar Montana Solo fragment; it does not grade how well the sync tracks the record. Montana's Percussion track also carries 22 notes at MIDI 87, outside the GM percussion range, which is a separate anomaly from the parentheses.
