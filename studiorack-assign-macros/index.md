# StudioRack: bind the 8 macros

Seven of the eight knobs carry a name and no assignment. A macro with no target controls nothing, so turning it does nothing. Only Rider Target is bound.

| # | Knob | Bind it to | Set to |
|---|---|---|---|
| 1 | Rider Target | Bass Rider, Target | -12 dB |
| 2 | Rider Output | Bass Rider, Output | 0 dB |
| 3 | DI Level | Parallel Split, Rack 1 Output | 75% |
| 4 | Amp Level | Parallel Split, Rack 2 Output | 45% |
| 5 | DIST Level | Parallel Split, Rack 3 Output | 15% |
| 6 | SUB Level | LoAir level | 20% |
| 7 | API 560 HF | API-560, 12.5 kHz band | 60% |
| 8 | CLA-76 | CLA-76, Input | 55% |

## Six clicks to bind one

1. Click Assign at the bottom right of the macro panel.
2. Click the macro knob you want to bind.
3. Click the plugin in the chain that holds the target.
4. Move the control you want the macro to drive. Moving it is what binds it.
5. Click Assign again to leave assignment mode.
6. Turn the macro and set it to the table value.

Range trick: while in Assign mode, set the macro low and the target low, then the macro high and the target high, to pin the travel to a useful range.

Save with the disk icon in StudioRack's top bar, then drag the rack back to User Library so assignments live in Fretless.adg.
