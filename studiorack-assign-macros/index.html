Binding the 8 macros, and where to set each one

Why nothing worked until now. Seven of the eight knobs carry a name and no assignment. A macro with no target controls nothing, so turning it does nothing and it reads zero forever. Only Rider Target is bound in this chain.

The panel, and what each knob should drive

Knob 1 has the gold ring, which means bound. Knobs 3 to 6 draw flat and dark, which means unbound.

How to bind one, in six clicks

  1. Click Assign at the bottom right of the macro panel. The knobs light up and the panel enters assignment mode.
  2. Click the macro knob you want to bind, for example knob 3, DI Level.
  3. In the chain on the right, click the plugin that holds the target, for example the first Parallel Split.
  4. That plugin opens. Move the control you want the macro to drive. Moving it is what binds it, so nudge the Rack 1 Output fader.
  5. Click Assign again to leave assignment mode.
  6. Turn the macro knob. It now moves the parameter you touched. Set it to the value in the table.
Range trick. While still in Assign mode, drag the macro to the lowest position you want, move the target control to match, then drag the macro to the highest position and set the target there. That pins the macro's travel to a useful range rather than the plugin's full sweep.
Save it when the eight are dialed. Click the disk icon in StudioRack's top bar to store the chain, then in Live drag the rack back into your User Library so the assignments live in Fretless.adg. Assignments are stored in the chain, so a saved rack keeps them.
