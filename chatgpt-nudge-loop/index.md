# ChatGPT Nudge Loop

A launchd job (`com.drwu.chatgpt-next`, `StartInterval 600`) types one audit instruction
into a ChatGPT conversation in Chrome every ten minutes and presses Send. It runs through
Apple Events JavaScript on a background tab, so it steals no focus, needs no computer-use,
and spends no Claude tokens.

## What this page shows

Every number is read from `~/.claude/skills/_shared/_state/chatgpt_next.log` when the page
is regenerated by `chatgpt_nudge_page.py`. Nothing on it is typed by hand.

## The two failure modes it survives

**A thread that fills up.** ChatGPT refuses new messages once a conversation hits its
length limit. The first build pointed at a single thread; that thread filled, and the job
logged 90 failures in one day while exiting 0 each time, so launchd reported a healthy
service. Targets are now an ordered list, a maxed thread is recorded in
`_state/chatgpt_next.dead`, and the job advances to the next id.

**An identical repeated sentence.** Sending the same words fifty times makes ChatGPT
restate its previous answer instead of finding anything new. The nudge rotates through
eight audit angles held in `chatgpt_next_msgs.txt`, counter in `_state/chatgpt_next.n`.

## Regenerate

```
python3 ~/.claude/skills/_shared/chatgpt_nudge_page.py
```
