Pipeline

Each song's six stems are transcribed independently:
  • Vocals + Bass → crepe (monophonic pitch tracker, viterbi, conf ≥ 0.5)
  • Guitar + Piano + Other → basic-pitch (ONNX, polyphonic)
  • Drums → librosa onset detection + 3-band spectral classification (kick/snare/hat)
  • Key + BPM → music21 Krumhansl correlation + librosa.beat
Output per song: 6 .mid files + _theory.json + _critique.md under ~/Projects/_outputs/_evidence/<artist>/<song>/. Drum kick/snare splits are approximate (librosa fallback); onset counts are reliable, piece labels are not.
