4. Verification

Both sets open in Live 11.3.43. The mix template instantiated 21 plugin devices, every one the intended plugin, with no fallback to the default document and no missing-plugin line. Counted from Live's own log at 16:31 on 2026-09-02: F6 Mono ×7, TransX Wide Mono ×2, then one each of CLA-2A Mono, MaxxBass Stereo, Voltage Amps Bass Mono, J37 Mono, Reel ADT Mono/Stereo, API-2500 Stereo, Abbey Road Plates Stereo, UADx SSL G Bus Compressor, PuigTec EQP1A Stereo and L2 Stereo, plus the two devices left on the spare return.

Four defects the load test caught

  • Duplicate device ids. Two devices in one chain shared Id="4", and Live called the whole document corrupt. Members of a device list are now numbered by position.
  • Live 9 device blocks. The UAD Pultec block came from a set Live 9.7.5 wrote, missing ids Live 11 requires. That source is out of the harvest entirely.
  • Dangling automation. Renumbering the pointee space left an envelope pointing at an id that no longer existed, logged as Invalid Pointee ID 10. A fresh template carries no automation, so the envelopes come out.
  • A silent identity swap. Each device block holds two class-id blocks. Replacing only the first let five lanes load Smack Attack while the file read correctly on inspection. Both blocks are now written, and the log shows the right plugin on every lane.

An offline validator now reproduces Live's rejection without a restart, learning from four reference sets which parent-child tag pairs Live always writes with an id, then flagging any member that lacks one. It reports clean on both sets and on Brandon's own working session.

5. What happens next

  • Four mic files. Drop them into the alignment set. Their path was not given, so no audio is placed yet.
  • Separate per microphone. Run each aligned mic through Demucs and DrumSep independently, then pick the clearest capture per lane by listening for bleed, attack, body and separator artifacts. A separator pass over the finished composite would bake every microphone compromise into every lane.
  • Seven stems in. Same length, same start, no normalisation, no processing.
  • Clip gain before compression. The large source changes are at 1:44, 2:46, 3:02, 4:18, 5:20, 6:22, 8:02 and 9:26. Handle genuine capture changes there and leave musical dynamics alone.
The source composite, measured. 10:35, mono, 24-bit, 44.1 kHz, about -22.5 LUFS with a -2.7 dBTP peak. Roughly 72 percent of its energy is below 315 Hz, concentrated near 79 Hz, and the spectrum falls sharply above 4 kHz, which matches the 24 kbps AAC source ceiling. That ceiling is the reason cymbal definition is taken from 2.5 to 4 kHz.
