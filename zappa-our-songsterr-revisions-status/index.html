Method

Revision history comes from songsterr.com/api/meta/<songId>/revisions, filtered to the author name Brandon chavez, with the full description text read for each one. A revision counts as matched to a printed chart only when the description names the source: Ryan Brown, DRUM Magazine, Groove Analysis, Daniel Bédard, or Drumnet. Live state comes from /api/meta/<songId>, comparing revisionId against our newest submission, and isBlocked identifies a moderator rejection.
