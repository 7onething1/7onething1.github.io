6. What blocked recovery

Lead typeTargetDetail
related_accountKhanoisseur_Second Twitter handle with 6k+ archived statuses; likely same person post-suspension. Kept distinct from primary corpus.
rate_limitweb.archive.org playbackIA playback returned 503 on 6/6 sequential probes at 04:10Z after ~800 fetches. CDX API still OK. Needs cooldown; resume run_timeline/run_wayback later.

The Internet Archive CDX index stayed available throughout, so ID enumeration ran to saturation. Playback of archived pages, which is where body text comes from, began refusing every request after roughly 800 fetches. The fetcher is checkpointed against SQLite and resumes from exactly where it stopped, so the corpus grows further on a later run without repeating work. Access controls on Thread Reader were not bypassed.
