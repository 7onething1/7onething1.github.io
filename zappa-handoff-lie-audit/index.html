--header is a one-shot that reports nothing when it fires blank

The header rewrite matches one pattern only:

re.sub(r'Every memory file with its own description, \d+ entries, '
       r'regenerated [\d-]+\.', ...)

The 2026-08-31 run replaced regenerated 2026-08-04 with last verified 2026-08-31, so the pattern stopped matching its own output. Every later --fix --header run changes nothing, prints nothing about it, and exits 0. I ran it during this audit and watched it append one entry and leave the count at 727 against 731 files.

The append-only claim does hold. The script writes new entries under one appended heading and never rewrites an existing line, which reading the source confirms.
