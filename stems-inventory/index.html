How to find any of it now

One hub, and a pointer inside every pool

Shortcuts are built, 186 of them, and every one resolves to a real folder:

~/Projects/stem-map/STEMS-FINDER

  • by-artist/ one folder per artist, holding a shortcut to each of that artist's pools across all three disks. Each shortcut is named with its disk and size, so you can see where the weight is before you click.
  • by-disk/ the same 93 pools grouped by the disk that holds them.
  • WHERE-ARE-THE-STEMS.txt the whole map as plain text, including the traps below.
  • refresh.sh rebuilds all of it from a fresh walk.

Inside each of the 93 pools there are now two files: _STEMS-FINDER, a shortcut back to the hub, and _WHERE-ARE-THE-STEMS.txt, the same text map. So landing in any stem folder on any disk gets you to all the others. Both sort to the top of a Finder window.
