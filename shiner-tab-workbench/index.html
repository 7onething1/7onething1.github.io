06Four traps that will bite

1. The folder numbers are three different numbering schemes

The canonical song folders are numbered by one order and the stem folders by another. They collide instead of missing cleanly, which is the dangerous kind:

Canonical 03_ is Broken Satellites. Stem 03 - is The Mutiny. Match on title, and ignore the leading digits entirely. Album order above comes from sources.yaml and the stem prefixes, which agree with each other.

2. Broken Satellites copy tracks, local only

The local file carries Rhythm Guitar Copy next to Rhythm Guitar, and a track literally named Copy next to the bass, plus a five-string standard B E A D G bass under a Drop C guitar. None of that is on Songsterr: the live revision returns five clean tracks with a Drop C bass. So the duplication happened locally. A part filled by duplicating another part is a duplication rather than a transcription, so run the octave-copy gate on the local file, and re-pull the live tab as the reference.

3. Asleep in the Trunk is in 3/4, and the book says 4/4

Songsterr's transcriber entered 3/4 explicitly. The MIDI metadata says 4/4 and so do the book cards. That is unresolved, and it changes every bar number in the song, so it has to be settled before bar-level correction on a 264-bar chart. The 2026-06-03 audit left the caveat that the song may open in 3/4 and move to 4/4.

4. Two songs cannot yield guitar evidence at all

Asleep in the Trunk and Jackie were separated to four stems, so their guitars are mixed into other. No amount of care on the tab will produce a per-attack guitar attribution from a stem that also contains keys and everything else. A pitch found in other does not prove the guitar played it. Both need re-separation to a six-stem model before they enter the queue.

07The correction queue

  1. The Mutiny: start here. It is the only song carrying real RhythmGtr [L] and [R] files, so the two-guitar split can be validated against ground truth rather than inferred. Whatever the splitter concludes on Mutiny is the calibration for the other nine.
  2. The Alligator: second, because it has an audio_truth.gp3 from the 2026-06-02 stem pass. That gives a prior to regress against, and a resolved key at high confidence.
  3. Not Too Much, So Far So, My Mirror Hates Me, Endless Summer: the clean middle. Full guitar layers, two GP staves, vocal and bass stems present.
  4. Lazarus: re-pull s5476396 first. The vocal and drum staves exist there, so nothing has to be built from scratch.
  5. Broken Satellites: re-pull the live tab, decide between s5084035 and the 2026-07-08 s5965143, then correct.
  6. Asleep in the Trunk, Jackie: re-pull the 2026-07 hand-built revisions, re-separate the audio to six stems, settle the Asleep time signature, then queue. The stem gap is a disk fact and does not change with the tab.
The bar the work has to clear. A finished transcription is not finished because a file exists or a script exited zero. It has to be checked against the stems for pitch, attack timing, duration, guitar ownership, doubled notes, tuning, and articulation, reported as measured numbers, and then checked for physical playability: string and fret realizability, tie chains, hand span, position movement at tempo, open-string behaviour. Every difference from the prior gets classified as supported correction, unsupported change, or unresolved ambiguity.
