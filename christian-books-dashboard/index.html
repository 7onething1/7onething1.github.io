lock Credential gates blocking the upload step

  • Ghost Admin API key is dead. Every write endpoint returns 401 (INVALID_JWT) even with fresh JWTs. Regenerate at on-brand.ghost.io/ghost/#/settings/integrations, then replace GHOST_ADMIN_API_KEY in ~/Desktop/project-audit-dashboard/.env.
  • Gumroad API token missing. Generate at app.gumroad.com/settings/advanced and add GUMROAD_ACCESS_TOKEN=... to the same .env.
  • Internet Archive S3 keys missing. Get them at archive.org/account/s3.php and add IA_ACCESS_KEY=... + IA_SECRET_KEY=... to the same .env. Also run pip3 install --user internetarchive.
  • Substack has no public posting API. Browser-based path via Claude in Chrome MCP (the substack-transfer-operator skill). Token-heavy. Decide whether to do this manually or via the browser walk.
